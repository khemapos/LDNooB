# Room: Bun & Tooling

## Summary
The project standardizes on **Bun** as its JavaScript runtime, package manager, and test/build runner.

## Commands
- `bun run dev`: Starts the Vite development server on port 1420.
- `bun run build`: Builds client and server static outputs into `build/`.
- `bun run check`: Executes SvelteKit sync and TypeScript diagnostics via `svelte-check`.
- `bun run tauri dev`: Runs the full native desktop environment.
- `bun run tauri build`: Builds the final native release binaries and installers.
